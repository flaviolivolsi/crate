# `focus` crate — instrumental electronic for deep work

A starter prose for a focus-music crate.

```
deep melodic techno and progressive house, fully instrumental (no vocals,
no spoken word, no chants), tempo around 118-126 bpm, atmospheric and
hypnotic rather than aggressive, in the style of Tale of Us, Mathame,
Mind Against, Massano, Innellea, Adriatique. Avoid mainstream EDM,
big-room, vocal house, and anything with breakdowns louder than the
rest of the track.
```

## Usage

```sh
crate new focus -d "<paste the prose above>"
crate add focus            # 20 tracks land in ~/Audio/crate/focus/
crate play focus
```

## Tuning

After auditioning the first batch:
- Too aggressive? Edit `.crate.json` and add "less peak-time, more sunrise" to the description.
- Too repetitive labels? Add "vary labels — include releases on Innervisions, Diynamic, Afterlife, Cocoon".
- Want it darker? Add "darker, more dub-techno influenced".
- Then `crate add focus` again with the refined description.
